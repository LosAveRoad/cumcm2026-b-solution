# Q3 修订证明与实现契约

策略标识：`q3_nine_net_contraction_v1`。活动实现为同目录 `searcher.py`，
`searcher_legacy.py` 是原包历史启发式，未由活动实现导入。

本文给出确定性、有条件的有限动作证明，不使用没有概率空间的“P=1”。
条件：固定全向源，位置在闭半径1800 m圆盘内；源数10--16，频道互异；
各源接收半径1000--1500 m；示向度误差绝对值至多1度；20 m内光学清除成功；
接口按模型接受并执行，测试未因现实期限或技术故障中断。

## 1. 覆盖

O加半径1000 m的八等分环。令 c=cos(pi/8)，t=1000/(2c)。
r<=t时选择O，距离<=t。r>=t时最近环点的距离平方不超过
f(r)=r²+10^6-2000cr。凸性给出 f(r)<=max(f(t),f(1800))=rho²，
rho=sqrt(4240000-3600000*cos(pi/8))=956.0510880488383 m。
边界角平分点取到该上界。

t不是各方向统一的最近站分界。8环可以用闭1000 m盘覆盖原点，
但不能用半径rho覆盖原点。该“存在近站”的命题不约束首次听到的站。

## 2. 发现集合与剪枝

仅完整扫描当前全部静默频道且响应被接受、有效后，才记为发现站。
尚未发现源必在场地减去发现站1000 m闭盘的连续残留内。
Q的透镜K_Q是其1000 m闭盘与场地交。只有证明整个K_Q已覆盖才跳过Q。

`certificates.py`把输入浮点坐标精确变为有理数，以有限矩形细分认证。
矩形若严格在某约束圆盘外则排除；若最大角点距离平方<=1000²则整个
矩形被一个发现站覆盖。其余细分；计算预算耗尽返回False，含义为
“未覆盖或未认证”，不能把它解释成已经证明存在残留。
所有剩余矩形均排除或认证才返回True。精确同中心盘包含直接认证。
输入及缓存键不舍入，不使用浮点最大值、额外正容差或有限采样代替证书。

即使实际接收半径>1000，Q也不能听到未发现源：若d=|QG|>1000，
在线段QG上取|QP|=1000。场地凸性保证P在K_Q。若S覆盖P，
则|SG|<=|SP|+|PG|<=1000+d-1000=d<=R_G，与未发现矛盾。

活动程序先扫描O，再每轮永久处理一个剩余环点。每轮仅跳过已认证透镜
或完整扫描该站。最多8轮；剪枝始终不成功也只会扫描全部9点。
由覆盖引理及N<=16的计数退出条件，发现阶段必完成。

## 3. 收缩

已知在S的示向度u和距离上界R<=1500，取P=S+(R/2)u。
对于r=|SG|∈[0,R]及|alpha|<=1度，

    |PG|² = r² + R²/4 - rR cos(alpha)
           <= max(R²/4, (5/4-cos(1度))*R²).

因此q=sqrt(5/4-cos(1度))=0.5001522816539066是收缩系数。
第一步q*1500<751<1000，之后每步也可听到全向源。各步误差可以任意
相关，既不假设零均值，也不通过重复原地测量缩小误差。

实现使用较宽系数0.501及1e-6 m外向坐标裕量，并把更新半径向上取整：
R_(j+1)=0.501 R_j+1e-6，R_0=1500。R_7≈11.883802151<20 m。
前六步测量，若near则就地清除；第七步直接清除。每源首次听到后最多
再用7次动作。对每一步的实际距离上界检查包含在离线测试中。

本证书没有使用内接多边形包围圆、未知真实距离轴点、越源猜测或概率论。
源固定，服务可从当前机器人位置直接到已保存读数推得的第一收缩点。

## 4. 预算、结果语义及外部限制

含进入和退出，A<=1+9*20+7N+1<=294<默认max_actions=900。
发现中的near清除计入对应源的7次额度，不额外重复计数。
总路程粗界<110 km，按5 m/s及各项动作时间，虚拟时间粗界<7小时。
现实期限不由动作数保证，程序按实际剩余时间建立单调时钟截止点。

只有发现完成且每个已发现源均收到清除成功时输出complete=true。
拒绝、无效响应、预算、截止时间、技术异常、收缩点no_signal、证书清除
失败均返回未完成；部分扫描不会进入发现集合。退出失败也报告失败。
